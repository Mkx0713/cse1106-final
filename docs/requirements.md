Temperature Monitoring System

Project Description:
This project uses a RPI and a C program to monitor temperature and alert the user when it gets too high.

Requirements:
1. Read temperature values from an input.
2. Compare the temperature with a set limit.
3. Display the current temperature and system status.
4. Turn on the LED when the temperature exceeds the limit.
5. Turn off the LED when the temperature is normal.
6. Save temperature readings and status to csv file.
7. Allow the program to run continuously until stopped.
